# Hong Kong 97 — disassembly → C/SGDK port map

Source: `disasm/hk97_trace.asm` (generated by `tools/trace65816.py` from
`work/hk97.sfc`). SNES addresses in LoROM (`file = (bank&0x7F)*0x8000 + addr-0x8000`).

## Overall flow (state machine)

```
RESET ($8000) → init → upload SPC ($CABB, driver at $8F:8000) → play cmd $01
  → TITLE+LANG+STORY ($BC65)
       title (tiles $84:8600 → VRAM $0000; pal $84:D4E7 + $84:A725)
       language select: object type 6 (cursor, table $80:BD01 = X 0x38,
         4 options Y 0x95/A5/B5/C5); $1252 = language (0=Zh?,1=?,2=?,3=special)
       if $1252==3: extra screens $C04F (2 pages) and $1252=0
       story: 3 pages per language (Story1/2/3_* at $BD15/$BD46/$BD77)
  → INTRO PAGES ($C0BF): 5 photos with text ($C2CF,$C373,$C41A,$C529,$C61F)
       1st page waits 600 frames ($C8E3 #$0258) or button; a button on the
       others switches to the "wait FFFF" mode; otherwise auto-advances 240 frames
  → GAMEPLAY (L_80826B)
  → GAME OVER ($C7E8: photo $87:AD9A, then a large uncompressed bank-$09 photo,
       texts $92EF/$9399) → back to the INTRO PAGES (loop $81AA)
```

## Infrastructure (SGDK equivalents)

| SNES | What | SGDK |
|---|---|---|
| NMI $83DC | processes the DMA queue, OAM DMA ($09A1, 136 sprites), CGRAM DMA ($0BC0) | `SYS_doVBlankProcess()` |
| $82ED/$833F | DMA queue to VRAM (descriptors at $0DC4, 10 bytes) | `VDP_loadTileData`/rescomp |
| $83B3/$83C3 | wait for vblank | `VDP_waitVSync()` |
| $818004/$818021 | fade out/in (INIDISP $9E, 15 steps, 1/frame) | `PAL_fadeOut/In` |
| $81803F | joypad: held $AE, pressed $B0, SOCD-clean, autorepeat $B4 (delay 10, rate 3) | `JOY_readJoypad` |
| $9DB8/$9DCE | custom LZSS decompressor (see below) | done offline in `tools/` |
| $B460/$B484/$B500 | score: 9 BCD digits $1244-$124C; $124D=pending points, injects 1/frame; digit = 2 8x16 tiles at ($124E,$1250)=(0x0C,0x01) | u32 counter + tiles |
| $C8E3 | wait N frames or button ($FFFF = button only) | C helper |

## Object system (48 slots)

Parallel arrays indexed by slot X (0=player):
`$0100`=flags (bit7 active, bit5 anim-done, bit4 collides, bit1 invisible),
`$0130`=type, `$0160`=anim id, `$0190`=anim frame, `$01C0`=frame timer,
`$01F0/$0790`=X lo/hi, `$0220/$07C0`=Y lo/hi, `$0250`=OAM index,
`$02E0`=alternate anim, hitbox: `$0430/$0460`=offset, `$0490/$04C0`=size
(nibbles from the anim table), sprite tiles `$0880/$08B0`=draw offset,
`$08E0/$0910`=size, `$05B0`=priority/OAM size, `$0940/$05E0/$06A0` =
per-type scratch fields. Spawn: `$9C2E` (A=type|anim<<8, $00=X, $03=Y).
Anim: tables `$8A15` (bank), `$8A24/$8A33` (ptr lo/hi), 15 types; anim
scripts with duration/frames; `$8AE7` = override for dynamic anims in WRAM $7E.

### Types

| # | What | Behavior (per frame) |
|---|---|---|
| 0 | Player (Chin) | $0ED6: 0=alive, 2=blinking ($0EDC=480f), 1/3=dead. Moves 2px, X 0x10-0xF0, Y 0x28-0xE0. Anim: idle 0x0A, ←0x02, →0x0C, ↑0x10, ↓0x0F. Y button (edge): shot (max 4, $0EC5). **The enemy spawner runs inside the player update** ($A97C) |
| 1 | Player shot | Y-=4; dies above the top (dec $0EC5) |
| 2 | Slow enemy | Y+=1 until 0x100 |
| 3 | Shooter enemy | Y+=2, X oscillates (sine table $A6C4); if \|dx player\|<8: every 0x18f drops type 0xA (max 4) |
| 4 | Zigzag enemy | Y+=2, X from table $A73F (loop) |
| 5 | Boss (head) | Spawns at (0x80,0x80), blinks 0x1E f (COLDATA flash), descends (table $A4B7), chases player X (±1px, 3px if close), HP 0x20 at $0700, locks the spawner ($0ECC=1) |
| 6 | Menu cursor | Driven by a table in [$05E0/$0940/$06A0]; input with autorepeat; $0640=selected line; $0670=state (0xFF idle/0xFE reset/5,6=confirmed) |
| 7 | Enemy | Y+=1 until 0xE0, anim 0x0D |
| 8 | Enemy | Y+=1 until 0xE0, anim 0x0E |
| 9 | Horizontal enemy | moves ← 1px (4px if \|dx player\|<0x18), dies X<0 |
| A | Enemy shot | Y+=3 until 0xE0 |
| B | Item/power-up | falls, dies at 0xE0; on "pickup" blinks 0x3C f |
| C | Player corpse | anim 6; on finish: $0ED6=1, $0EDA=120f → game over |
| D | Large explosion | 0x18 fragments (offsets $A0FC) every 2f, each type E |
| E | Explosion fragment | anim 6, vanishes on finish |

### Enemy spawner ($A97C, tables)

- `$AA54`: type sequence (bytes, 0xFF = loop), index $0EC7
- `$AA67`: pairs (delay, type-2) 0xFF-terminated, index $0EC6
- type 9 in the table = special: X from the positions cycled in `$AA40`
- real spawn = table_type + 2; delay between spawns in $0EC8
- If the boss is active ($0ECC) or on delay: nothing. Every 30 kills ($0ED4≥0x1E): boss.

### Collisions (AABB, $ABE7 per frame)

- enemy×player ($AD62 type→handler): 1=$0ED6=1 (death), 2=death with corpse
  (spawn type C), 3=non-fatal hit ($0ED6=2, blink 480f), 4=boss (only if $0ECE)
- shot×enemy ($AF6A type→handler): 0: +5 pts, explode (type B... spawn 0x0B),
  drop item from table $AF41 (type=entry+6, 0=nothing); 1: HP $0700, on zero
  +50 pts, large explosion (type D) + drop; 2 (boss): HP 0x20, on zero
  +100 pts, releases the spawner
- points go to $124D (pending), the scoreboard injects them per frame

## LZSS decompressor ($9DCE)

Command stream, one byte per command (bits 7-6 = mode):
- 00: match dist=(b&0x3F... b>>2)+1 back, len=(b&3)+3
- 01: match dist 12 bits ((b>>2)&0xF | next<<4)+1, len=(b&3)+3
- 10: match dist 10 bits ((b&3)<<8 | next)+1, len=((b>>2)&0xF)+7
- 11: counts the following 1 bits (sub-mode from the bits after the 11):
  - sub0: long match, len=((b2&0xF0|b&0xF)+7 | carry<<8), dist=(b2&0xF)<<8|b3
  - sub1: literals, len=(b&0xF)+1
  - sub2: very long match len+0x207, dist 11 bits (ROR mix)
  - sub3: long literals, len=((b&3)<<8|next)+0x11
First word of the stream = decompressed size. Implemented in
`tools/hk97.py` (validate against expected sizes: pal=0x200, tiles=0x4000/0x7000).

**IMPORTANT (gameplay background):** `$BDF3` is called once per run — the
background advances each run ($1253 cycles 0..6), it does **not** flash
during play. The epic "flash" is the boss (COLDATA add/sub) and the explosions.

## Notes for the MD port

- Screen: SNES 256×224 → MD H32 (`VDP_setScreenWidth256()`); same coords.
- BGs: photo = 256×224 image (tiles+sequential map); use PAL0+PAL1.
- Sprites: SNES OAM 16×16/32×32 (OBSEL $2101); MD SPRITE rescomp.
- Color math (boss/intro COLDATA flashes) → approximate with a blinking
  palette or `VDP_setHilightShadow`.
- Cursor $211B/C multiply → plain multiply in C.
- Text: rendered as extracted images (no font needed).
